## 已覆盖的关键行为

- 完整 BITS 使用独立程序、配置、状态、日志和工具目录；内部批次采集不安装 mon-sensors 交互入口，管理端使用 bits 账户及 bits-center-* 服务。
- 固定布局模块纳入程序哈希清单；未绑定工具、未知配置、修改过的文件和活动任务阻止安装或替换。
- 原任务协议保持兼容，无效任务在领取前拒绝；重复项目可执行，实际进程有时长约束和退出清理，完成后不继续轮询新任务。
- 停止采集、封存、报表、上传、下载哈希验证及完成记录按阶段执行；重复恢复保持六份结果文件哈希一致。执行结果与未知传感器质量分别表达。
- HTML/JSON 机器报告、流式 Excel、长日志与中断恢复回归通过；API、采集和报告只导出 Primary 时序，缺失读数保持空值。
- 实际已发布的 0.2.5 节点包完成批次后分离，0.3.0 核验并导入历史；未完成批次、损坏文件和批次冲突拒绝导入。重复导入、完成状态重试及回退旧包保持原日志和回执字节不变。
- 实际 0.2.2 节点包的显式分离、更换及回滚路径通过；此项不等同于已逐一验证所有中间版本的历史导入。

## 尚未验收与迁移边界

- 本轮新包尚未在 215 控制机或指定物理节点安装；真实 sckocp 采样、独立内核、SELinux 强制模式与长期硬件稳定性需现场验收。
- RHEL、ARM 不因上述矩阵自动获得支持结论；MLC 全量测试、SPEC 原文件导入后的完整压测、P95 长时间负载与 cyclictest 实时延迟仍按硬件环境验收。
- 原 sckocp 授权和本地接口边界保持不变。本轮重构不是抵抗设备完整 root 权限逆向的证明。
- 旧完整管理端的数据库、共享存储、账户及凭据迁移未自动化；需要在维护窗口核实实际部署后制定迁移方案。安装器会保留已有部署并停止，不能把卸载旧包再配置新中心当作数据迁移。

操作见[迁移与回滚](../deployment/MIGRATION-0.3.md)、[完整系统部署](../deployment/DISTRIBUTION.md)和[旧系统增强](../deployment/BITS.md)。本次不重写已有 Release/tag，也不改写历史日志或完成记录。
