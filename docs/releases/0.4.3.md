# BITS 0.4.3

新增中心、节点通用的完整卸载命令。适用于 RPM / DEB，不依赖主机名或 IP。

```text
bits-center uninstall --purge
bits-node uninstall --purge
```

- 先显示清理范围，再输入确认；`--dry-run` 只预览，`--yes` 用于已确认的自动化。
- 删除对应角色的软件包、配置、测试记录、报告、采样文件、自动升级备份和服务注册。最后一个角色卸载后清理标准 `bits` 服务账户。
- `--include /明确路径/bits-center-...` 或节点对应名称可加入手工保存的安装包、历史安装备份目录，不扫描整个磁盘。
- 运行、上传等未完成工作阻止卸载。包管理器失败保留数据并恢复原服务；后续文件清理中断时输出继续清理命令。
- 另一角色、原版 sckocp、网络配置、独立保存的副本及系统共享日志保留。删除为文件系统删除，不是介质安全擦除。

常规 `dnf remove` / `apt remove` 继续保留业务数据。完整范围和恢复方法见[操作手册](../deployment/BITS-INDEPENDENT.md)。源码包、RPM / DEB 和 `VERIFICATION.json` 来自同一验证提交；历史发布附件保持不变。
