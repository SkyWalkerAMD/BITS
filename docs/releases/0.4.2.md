# BITS 0.4.2

RPM / DEB 现在负责通用安装升级流程，适用于所有控制端和节点，不依赖指定主机或地址。

- 已配置的机器直接执行 `dnf install/upgrade ./bits-*.rpm` 或 `apt install ./bits-*.deb`。包内自动检查未完成工作、停服、完整备份、更新并恢复原本运行的服务；原本停用的服务保持停用，开机启动设置保留。
- 正在执行、等待开机、报告生成、上传和未完成清理时拒绝升级。节点维护锁阻止检查与停服之间接入新任务；旧节点有兼容处理。
- 私有备份保存在 `/var/backups/bits/center/` 或 `/var/backups/bits/node/`。备份失败保留旧包并恢复原服务；保留既有配置、证书、BMC 模板与报告。
- 首次安装后，中心执行一次 `bits-center setup --address 地址 --network 网段 --apply`，节点执行一次 `bits-node enroll --file 连接文件`，成功后自动启用并启动对应服务。自定义部署可使用 `--start=false`。

支持从正式版 0.4.0 / 0.4.1 直接升级。旧发布包保持不变。没有初始配置的系统只安装软件；网卡、防火墙和原版 sckocp 授权仍由管理员配置。

安装命令、备份与故障恢复见[操作手册](../deployment/BITS-INDEPENDENT.md)。验证结果随本版 `VERIFICATION.json` 提供。
