# BITS 0.4.0 正式版

本版将 0.4 网页工作台作为正式发行版交付，包含中心、节点两个角色包，提供 RPM 和 DEB。原 alpha 标签和附件保留。当前下载见 [v0.4.0 Release](https://github.com/SkyWalkerAMD/BITS/releases/tag/v0.4.0)，操作见[安装与升级手册](../deployment/BITS-INDEPENDENT.md)。

## 本版变化

- 系统在线即可监控硬件。空闲节点显示日常读数；压测开始与结束自动切换采集来源，无需新建批次，历史报告和证据保持封存。
- 调整 VCCIN / PSU 补充读取的探测、读数预算和传感器目录缓存；失败或缺失仍显示“—”，旧测量不伪装成新读数。
- 保留自定义 BMC 凭据模板、添加节点时选择或新建模板、管理口身份核对与自动绑定。模板编辑影响后续绑定；现有绑定使用保存时的凭据。
- 任务分发、运行总览与测试节点统一区分系统在线、已关机可唤醒、已开机等待系统、状态待确认。任务组只有明确开始后才按需开机及压测。
- 支持桌面与手机查看逐插槽、逐核心、趋势、任务步骤和报告；执行、采样质量与文件交付分别记录。

## 安装与升级

程序版本 `0.4.0`，RPM `0.4.0-1.el8`，DEB `0.4.0-1`。节点包包含工具和本地采集、报告适配器；原版 sckocp 仍需独立安装并按原流程授权。

alpha.7 用户需先完成所有批次，再分别停止中心、节点服务，完成私有数据备份并安装对应的新包，随后启动服务。保留现有节点身份、连接文件、证书、BMC 模板、绑定和报告；不要重新初始化或登记原节点。持续监控需要两端均为 0.4.0。更新不修改网络或开机启动策略，已有的成功交付后 30 分钟空闲关机规则继续生效。

0.3.0、OCRUN 和 BITS-o 使用不同协议，本版不提供它们的原地迁移。具体步骤及回退要求见[操作手册](../deployment/BITS-INDEPENDENT.md)。

## 发布验证

安装包、源码和 [VERIFICATION.json](https://github.com/SkyWalkerAMD/BITS/releases/download/v0.4.0/VERIFICATION.json) 来自同一提交与同次私有 Linux Actions，公开 [SHA256SUMS](https://github.com/SkyWalkerAMD/BITS/releases/download/v0.4.0/SHA256SUMS) 覆盖所有直接附件（不含校验文件自身）。验证清单记录：

- Go 协议、并发竞态、恢复、节点监控和 200 节点事务检查，以及静态分析、源码导出边界与文档路径。
- Rocky / AlmaLinux 8、9、10，Debian 11、12、13，Ubuntu 22.04、24.04、26.04 的实际包安装、systemd 服务、短程工作负载与交付；共 12 个 Linux 容器环境。
- Rocky 8 RPM 与 Ubuntu 22 DEB 从发布的 alpha.7 实包升级：活动服务拒绝升级、停服安装、身份和模板保留、旧证据哈希不变、升级后日常监控及新批次交付。
- 桌面和手机浏览器操作，包括日常监控、批次切换、断连显示、BMC 模板和节点状态。

云端传感器和 BMC 状态使用模拟夹具，容器共享宿主内核。上述结果不替代真实传感器有效性、物理 BMC 开机、各发行版独立内核、多天满负载和 200 台物理机器的现场验收。正式发行状态不自动赋予机器硬件合格结论。
