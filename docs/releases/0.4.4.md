# BITS 0.4.4

系统终端改为紧凑工作区，文件传输使用独立的本地 / 远程双栏窗口。

- 终端随可用窗口伸缩，增加全屏、字号调整和行列显示；切换文件窗口不会断开 SSH。
- 本地支持选择多个文件、打开文件夹并浏览子目录；远程支持路径输入、上级目录、刷新及下载。
- 多选或拖拽上传，队列显示逐项进度、完成和失败，支持暂停待上传项、取消和失败重试。每项任务保留加入队列时的目标目录；同名文件不覆盖。
- 单个文件仍限制 1 GiB。下载由浏览器管理；文件窗口的队列跟踪上传。文件夹用于浏览和选择其中的文件，不递归上传目录。

已经使用 0.4.3 节点的系统只需更新中心即可使用新版终端界面；同时提供配套 0.4.4 节点包。已有 SSH 模板、BMC 配置、节点和报告保留。

```bash
dnf upgrade ./bits-center-0.4.4-1.el8.x86_64.rpm
```

更新后使用 Ctrl+F5 刷新网页。DEB 使用 `apt install ./bits-center_0.4.4-1_amd64.deb`。

发布证据覆盖同一提交的 Go race / vet、12 个 Linux 容器环境、0.4.0 / 0.4.1 / 0.4.2 / 0.4.3 的 RPM / DEB 实包升级，以及真实 OpenSSH / SFTP 浏览器流程。具体结果见随包 `VERIFICATION.json` 和 `SHA256SUMS`。源码包对应本次构建提交，历史版本附件保持不变。
