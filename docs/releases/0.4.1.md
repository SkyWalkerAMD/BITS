# BITS 0.4.1

本版增加独立的单台 / 批量唤醒，以及已结束批次和报告的单条 / 批量永久删除。中心与节点请配套升级至 0.4.1。

## 手动唤醒

- 运行总览、测试节点、节点详情和硬件实时监控提供“唤醒机器”；任务分发支持选择多台机器统一唤醒。
- 确认窗口列出机器名单。中心逐台检查 BMC，只发送开机指令，等待系统连接，不创建或开始压测。
- 每台机器独立记录等待、连接成功、失败或超时。重复提交不重复执行；中心重启后核对已保存意图，结果不明时不盲目重发。
- 新版节点手动唤醒后保持开机，适合日常监控；下一次明确开始压测后恢复原有任务关机策略。原先配置“完成后保持开机”的节点继续保持开机。

## 永久删除

- 在“结果与报告”和“压测批次”中单条删除，或勾选多条统一确认。批次详情也提供删除入口。
- 仅允许已交付、已取消或已人工关闭的批次。未开始的草稿先取消；运行、上传、等待开机和待处理批次不能删除。批量请求先检查全部选择，再开始清理。
- 确认后永久删除中心的批次记录、事件、报告、遥测、日志及回执，清理空任务组。没有回收站；节点本地副本和已有独立备份不在此操作范围。
- 清理进度持久保存，中断可继续，失败可重试。仅保留批次 ID、归属与删除进度，防止迟到上传恢复已删数据。

## 升级与验证范围

从 0.4.0 升级前，先结束任务并停止相应角色服务，完整备份配置和数据，再安装同角色 RPM / DEB。中心从 schema 3 升级至 schema 4；有已登记节点时生成私有一致性数据库备份。回退必须使用升级前完整快照及对应旧包，不能让旧中心打开新库。

操作步骤见 [安装与升级手册](../deployment/BITS-INDEPENDENT.md)。软件验收证据随本版 `VERIFICATION.json` 提供，包括 Go 并发 / 恢复测试、浏览器桌面 / 手机交互、12 个 Linux 容器环境和 0.4.0 RPM / DEB 实包升级。云端 BMC 使用模拟驱动，传感器使用模拟数据；物理机器开机、真实硬件和长时间运行仍需现场验收。
