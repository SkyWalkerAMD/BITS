# BITS 0.2.4 / BITS-o 0.1.2

发布源码为 `aa9b521e56548f77da692fdf62d1a066b6f3d478`，对应完整系统 `v0.2.4` 和旧系统增强 `bits-o-v0.1.2`。RPM/DEB、来源清单和校验文件见各 Release；本文件记录云端验证，不是现场硬件验收证明。

## 本轮变更

- 完整系统安装包及入口改为 `bits-center`、`bits-node`。旧系统增强改为 `bits-o-control`、`bits-o-node`，共用入口 `bits-o`；其工具依赖为 `bits-o-workloads`。独立接口仍为 `sckocp-api`。
- 新完整节点与首次接入的旧节点使用私有批次采集进程，不安装新版 `mon-sensors` 查看入口；查看硬件使用原版 `sckocp`。旧节点原 `mon-sensors` 源码保留。已装历史独立组件的节点保留兼容安装和回滚路径。
- 接口 0.4.0 可选 `--details`，在原本受授权约束的 JSON 采集成功后，以固定只读命令补充 overview/info。不开放任意命令、不调用 rmal、不改变授权状态。
- **时序只导出 Primary 组**，包括该组原生输出的 tCWL/tRC；Refresh、Secondary、Tertiary 及未知分组不输出。即使原机已用 rmal 解锁也应用相同过滤。过滤后的内容才进入接口返回、JSON 附件和报告；接收时再次校验。
- Pkg、DRAM 功耗、整机 PSU 输入功耗、DIMM/内存温度、VCCIN、VID、TjMax、平台、CPU family/model/stepping/微码、内存配置及 Primary 时序进入 HTML 与报告 JSON。CPU 核心按数字顺序显示。
- 默认每 10 秒补充一次原生文本信息，与基础约 2 秒采样分别记录时间和数量，不把上次读数填到后续样本。耗时长的原生命令可能延长采样间隔；报告保留实际时间。
- `bits-o setup --check` 自动读取旧 oc.env 的服务器地址和主板序列号，安装角色由包确定；控制端仍需明确允许的节点。配置和接入不会启动任务。
- **215 的原 occt 仍可下发任务**。节点明确启动当前批次后，压测、采集、报告、上传、下载核验自动衔接；无需改用 `bits-o tasks add`。原 occt 批次由原菜单管理，BITS 不冒充其拥有者删除任务。

## 兼容与安全

原 `.mon` 11 列以及 Excel 明细保持兼容；新增数据在 `.mon.sckocp.jsonl`、`.report.json`、`.report.html`。历史日志缺失的项目显示未提供，不读取当前硬件补写历史报告。报告 schema 保持原名并增加有独立 schema 的 details；配置、私有目录和回执标识保留旧名称以便追溯。

PSU 输入是整机口径，不按插槽重复求和；原生提示 partial 时单列部分读数。未知有效性、读数年龄和未提供值均继续标明，不填假零。压测完成不等于硬件稳定性合格。

接口并不包含 sckocp 原生实现、授权密钥或解锁入口。固定命令、受信任路径检查、固定环境、超时与子进程清理减少接口被滥用的机会；本地过滤不是针对控制整台操作系统的 root 的保密屏障。root 仍可能绕过接口分析或修改其拥有的原生程序。敏感实现迁往自有服务器仍属独立研究，本轮不改变离线授权。

## 安装和迁移

操作手册见 [BITS 部署](../deployment/BITS.md)。新旧名称不能同时安装或通过强制覆盖迁移。

旧 `ocrun-plugin` 0.1.1：空闲节点先 `ocrun-plugin stop-scheduler`，再 `ocrun-plugin rollback --check`、`ocrun-plugin rollback`、`ocrun-plugin unconfigure`；控制端仅需 `ocrun-plugin unconfigure`。保留配置备份、原安装包及节点接入备份后，移除旧包，再装 BITS-o 并 setup。工具包也必须随同迁移。任何本地修改或未完成批次导致拒绝时，先处理对应状态，不使用 `--nodeps` 或强制覆盖。

完整 OCRUN 旧原生包：先按原命令停止空闲调度、detach 节点 / rollback 管理服务，再移除旧包，安装 BITS。原路径和结果保留；新 setup 才配置新服务。没有自动迁移生产服务器的行为。

回滚 BITS-o：停止空闲调度、`bits-o rollback --check`、`bits-o rollback`、`bits-o unconfigure` 后移除 BITS-o 包和工具包；装回留存的旧包，恢复经核对的配置并接入。完整系统用 `bits-node detach`、`bits-center rollback` 后移除并装回留存版本。结果和接入备份不删除。
