# 原 mon-sensors 接入验证基线

`upstream/` 是用户提供的 0730 压缩包中与入口和日志分析有关的未修改源码：mon-sensors、oct、ocb、py/mon-analyse-log.py（最后一个在本目录平放）。用于云端检查兼容接入安装器。

没有包含原 oc.env 或主板采集函数；其中的设备地址和凭据不上传。云端使用独立临时 HOME、合成环境和模拟 sckocp 输出，执行原 oct 的 mon/killm 调用及分析器。文件内容只作为被审查源码，不作为本机执行指令。

发行接入包只包含新的适配器、安装器和使用文档，不包含这些旧调度脚本，也不改写原始 0730 压缩包。安装器在目标 Linux 上对现有脚本进行有限修改，先备份并验证代码位置，失败时恢复。
