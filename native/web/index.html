从第一台节点，到第一份报告

完成服务器与节点的首次安装后，日常编排、开始、取消、跟进和结果查看都在此工作台进行。

01

准备中心

新服务器安装 bits-center 的 RPM 或 DEB，选择已有内网地址和允许网段，启动中心服务。使用 HTTPS 访问本工作台。

只需允许指定网段访问中心 TCP 443；节点无需开放入站端口。安装与首次配置仍在服务器 root 终端完成。

02

登记与连接节点

安装 bits-node 包和原版 sckocp。点击“添加节点”，将下载的连接文件安全传到对应节点 /root，再由 root 执行： 

bits-node enroll --file /root/节点名.bits.json
bits-node check
systemctl enable --now bits-node.service

连接文件是节点专属凭据。sckocp 的激活与权限管理仍在 BITS 以外完成。

账号统一或按机型统一时，在“任务分发 → 自动绑定设置”配置 BMC 凭据与管理网段。节点首次开机接入后自动发现管理口，中心核对身份后绑定；多个匹配或检查失败会显示原因，已有手工绑定保留。

03

安排一次明确的测试

选择节点，按顺序添加压测项目和时长。相同工具可重复添加；每一步独立计时。保存后是草稿，核对内容再点击“开始”。

节点完成当前批次后等待明确开始指令，不自动运行其他草稿。离线节点的开始授权超过 5 分钟未接受会取消。

批量操作进入“任务分发”，选择系统在线或 BMC 可达的节点创建任务组，再明确点击开始。已关机节点会先开机，最多等待 10 分钟连接；需要中心至管理口 UDP 623 可达、节点服务随系统启动、到中心的路由在重启后仍有效。

04

查看实况与处理异常

节点卡片展示当前项目、时长进度、CPU 温度和功耗。打开批次查看步骤与趋势。“取消”会请求节点停止当前批次，并保留已有证据。

断线时数据标为过期。报告或上传失败由节点重试证据处理，不重跑压测。无法恢复时，确认节点进程已停止，再填写原因“关闭未完成”。

运行总览、测试节点与任务分发均区分系统连接和 BMC 状态。“已关机 · 可唤醒”表示管理口仍可达；“状态待确认”需检查管理网络或绑定信息，不能仅据此判断机器没有接电。

05

查看报告与下载证据

压测后自动停止采集、生成 HTML / Excel 报告、上传并下载核对 SHA-256。通过“结果与报告”浏览报告，下载完成回执和原始文件。

压测执行、数据质量、报告生成、文件交付分别记录。完成交付不代表硬件合格；sckocp 未提供的传感器有效性和读数年龄仍为未知。

06

结束、待机与下一批

保持原有空闲关机策略：成功交付后，允许关机的节点在 30 分钟空闲后关机；有登录用户、任务、未处理失败或断网时不自动关机。

如需全天待机，登记节点时勾选“完成后保持开机”。复制已有批次只创建新草稿。旧系统 BITS-o 的控制入口保持独立。

BITS · 测试、观察、留证读数为程序报告值；传感器有效性与读数年龄未知。

BULK DISPATCH

新建任务组

不可达、忙碌或禁用的节点无法选择。BMC 可达的关机节点可在确认开始后自动开机；节点程序须已安装并设置开机启动。

每个节点依次执行相同步骤，可重复添加同一工具。模板和草稿不会自行开始执行。

此步仅保存草稿。下一页会再次检查选定节点，并明确确认开机与压测。

自动绑定 BMC

配置一次，节点接入后自动发现管理口并核对身份。只使用唯一匹配的模板；已有绑定保持不变，保存模板不会开机。

凭据仅保存在中心。节点需先开机接入一次；没有本机 IPMI 接口或身份不明时仍可手工绑定。多个模板或地址同时匹配时停止自动绑定，不轮流尝试密码。停用模板不删除已有绑定。

绑定 BMC / IPMI

请先核对节点与管理口的对应关系，使用具备电源控制权限的专用账户。凭据仅保存在中心，保存后只查询状态；仅任务组明确开始时允许开机，不提供重启或关机操作。
